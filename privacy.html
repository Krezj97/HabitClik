Política de privacidad

HabitClik es una aplicación de seguimiento de hábitos. Esta página explica lo que guarda la versión actual del sitio web y sus límites.

Qué información guarda

Al crear o marcar hábitos, la aplicación guarda los nombres de tus hábitos, categorías, objetivos semanales, fechas, registros de progreso, rachas y preferencias de avisos. La experiencia y las insignias se calculan localmente a partir de esos registros. Cuando eliges un archivo de sonido personalizado, ese archivo se guarda en el almacenamiento local del navegador.

Dónde se almacena

Los hábitos y ajustes se guardan mediante localStorage; el archivo de audio propio se conserva con IndexedDB. La versión web actual no tiene registro de cuentas, sincronización entre dispositivos, publicidad ni análisis de uso de terceros incorporados. HabitClik no envía esos registros ni tus archivos de audio a un servidor propio.

Acceso a internet y alojamiento

Los archivos de la web se sirven mediante GitHub Pages. Para cargar y actualizar la aplicación, el dispositivo contacta con este servicio, que puede tratar datos técnicos de conexión conforme a sus políticas. Una vez precargados los recursos, muchas funciones pueden funcionar sin conexión. No afirmamos controlar los registros técnicos del proveedor de alojamiento.

Notificaciones y permisos

En la web, las notificaciones del navegador requieren permiso y pueden depender de que la página esté abierta. En la APK Android, las notificaciones locales se programan directamente en tu dispositivo tras conceder el permiso del sistema; no requieren una cuenta ni enviar tus hábitos a un servidor. Puedes desactivarlas en los ajustes de Android o de HabitClik. La entrega puede retrasarse por el ahorro de batería. Exportar un aviso de calendario genera un archivo que tú decides importar: HabitClik no accede directamente a tus calendarios.

Exportar y eliminar información

Desde la página principal puedes pulsar Exportar datos para descargar una copia JSON de hábitos y registros, o Importar datos para restaurarla. El archivo JSON no incorpora tu audio personalizado. Puedes eliminar hábitos individualmente. Para eliminar todos los datos locales y el audio, utiliza la opción del navegador o de Android para borrar los datos del sitio HabitClik. Eso es irreversible si no guardaste una copia.

Pagos y cuentas

Premium aún no ofrece cobros, compras ni cuentas. No se solicitan datos de pago. Si se añaden suscripciones, cuentas, sincronización o notificaciones remotas, será necesario actualizar esta política y la información de privacidad de Google Play antes de activarlos.

Contacto y responsable

Para comunicar incidencias sobre esta versión puedes utilizar el repositorio del proyecto en GitHub. Antes de distribuir HabitClik comercialmente mediante Google Play, el responsable de la publicación debe incluir aquí sus datos de contacto públicos y revisar los requisitos legales y de privacidad que le correspondan.

Esta política describe la versión web actual y no certifica por sí sola el cumplimiento de todas las obligaciones de una futura aplicación Android.
